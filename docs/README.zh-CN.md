**方向感知大选择性卷积模块**

一个用于计算机视觉方向特征建模的 PyTorch 模块。

## 项目简介

DLSK（Directional Large Selective Kernel，方向感知大选择性卷积）结合了局部深度卷积、垂直与水平条形卷积，以及用于预测三个分支权重的空间注意力机制。

该模块旨在作为一种实验性的特征增强模块，应用于具有明显方向性或细长结构的计算机视觉任务。

潜在应用领域包括：

- 农作物器官检测
- 裂缝检测
- 道路提取
- 血管分割
- 文本行检测

以上均为潜在应用场景，并不代表该模块已在所有任务上完成验证或取得性能提升。

## 模块设计

对于形状为 `(B, C, H, W)` 的输入特征图 `x`，DLSK 的处理流程如下：

1. 使用 `3×3` 深度卷积提取局部特征。
2. 使用带膨胀率的 `11×1` 深度卷积建模垂直方向的上下文信息。
3. 使用带膨胀率的 `1×11` 深度卷积建模水平方向的上下文信息。
4. 将三个特征相加，并通过 `1×1` 卷积进行特征融合。
5. 分别计算沿通道维度的平均池化和最大池化描述符，将二者拼接后输入 `5×5` 卷积，生成三个空间注意力图。
6. 使用三个注意力图对对应分支的特征进行加权，并将加权后的特征相加，得到最终输出。

**实现说明：** 在当前实现中，垂直和水平条形卷积均作用于局部卷积生成的特征，并且按顺序执行，并非三个完全独立的并行分支。注意力生成层使用的是标准 `Conv2d(2, 3, 5)`，而不是深度卷积。

## 安装

克隆项目仓库：

```bash
git clone https://github.com/joysite/DLSK.git
cd DLSK
python -m pip install -r requirements.txt
```

如果需要以可编辑模式安装项目并进行开发：

```bash
python -m pip install -e ".[dev]"
```

## 快速开始

```python
import torch
from dlsk import DLSK, DLSKBlock

# 创建输入特征图
x = torch.randn(1, 64, 80, 80)

# 使用 DLSK 模块
module = DLSK(dim=64)
y = module(x)

print(y.shape)
# torch.Size([1, 64, 80, 80])

# 使用 DLSKBlock 包装模块
block = DLSKBlock(dim=64)
z = block(x)

print(z.shape)
# torch.Size([1, 64, 80, 80])
```

## 模型集成说明

DLSK 保持输入特征的通道数和空间尺寸不变，因此，当周围网络需要相同形状的特征张量时，可以将其插入 CNN 中的合适位置。

将 DLSK 集成到 YOLO 或其他深度学习框架时，可能需要根据具体框架进行相应适配，例如：

- 注册自定义模块；
- 修改模型解析器；
- 调整模型配置文件；
- 检查输入输出通道与网络连接关系。

当前仓库提供的是独立模块的基础实现，不包含完整的 YOLO 或其他检测框架集成代码。

## 当前局限性

- **独立注意力门控：** 三个注意力图使用独立的 Sigmoid 函数生成，其权重之和不受约束，不一定等于 1。
- **串行方向卷积：** 当前实现中的垂直和水平条形卷积依次执行，而不是完全独立的并行分支。
- **性能依赖环境：** 实际运行速度和计算延迟会受到硬件架构、运行环境及部署方式的影响。
- **不包含完整检测器：** 当前仓库不提供预训练权重，也不包含完整的目标检测模型。
